# Kịch bản video demo (gợi ý ~7–9 phút)

Chuẩn bị: Firebase đã cấu hình + seed; emulator/thiết bị đặt vị trí ở TP.HCM; ghi màn hình + micro.

| Thời gian | Nội dung | Chú ý |
|---|---|---|
| 0:00 | Giới thiệu nhóm, ứng dụng, kiến trúc 20 giây | Nói rõ phần nào là mô phỏng (OTP SMS, liên ngân hàng, danh mục tiện ích) |
| 0:30 | **Nhân viên** `officer1`: tạo khách hàng mới (`customer3`) | Cho thấy 2 giao diện khác nhau |
| 1:30 | Nhân viên: mở tài khoản tiết kiệm (kỳ hạn lấy từ chính sách) và khoản vay | |
| 2:15 | Nhân viên: tab Lãi suất → đổi 12 tháng, áp dụng cho sổ hiện có | |
| 2:45 | Đăng xuất → **khách hàng** `customer1`: 3 loại tài khoản, khác biệt hiển thị | Lãi/tháng, số tiền trả mỗi tháng, lịch trả nợ |
| 3:45 | Chuyển 1.000.000 ₫ sang `customer2` → OTP (SMS mô phỏng) → biên lai → kiểm tra bên `customer2` | |
| 4:45 | Chuyển 15.000.000 ₫ khi **chưa eKYC** → báo cần eKYC; nộp eKYC → nhân viên duyệt → chuyển lại: mỉm cười + OTP | |
| 6:00 | Tiện ích: tiền điện, nạp điện thoại, vé máy bay; lịch sử tháng | |
| 6:45 | Bản đồ: định vị → đường đi bộ tới chi nhánh gần nhất | |
| 7:15 | Chatbot: "xem giao dịch tháng này", "thanh toán tiền điện" → nút mở màn hình | |
| 7:45 | Nạp tiền qua cổng SANDBOX (và VNPay sandbox nếu đã có tài khoản) | |
| 8:15 | Khóa tài khoản `customer2` → đăng nhập bị từ chối; kết luận + giới hạn | Nhắc giới hạn trung thực |
